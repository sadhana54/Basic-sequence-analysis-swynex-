# Basic-sequence-analysis-swynex-
Project Title: Basic Statistics and Sequence Analysis Using Python

Objective: To perform basic statistical analysis of DNA sequences using Python.

Tools Used: Python, GitHub and FASTA format.

Analysis: The project calculates sequence length, nucleotide composition (A, T, G and C), GC content, ambiguous nucleotide count and average sequence length.

Outcome: Successfully performed basic DNA sequence analysis and generated a statistical summary report.
